# First-pass scrub and final review checklist

This is a sanitized export of the current local scaffold, not a tested public distribution. The live installation was not changed. The mailbox repository is public; known credentials, personal identifiers, private absolute paths, private network addresses, raw PSC excerpts, and private context fields have been removed before upload.

## Flagged and retained for Strider's final verification

- Generic software interfaces named TSC, PSC, Judge, core, gate, crate, seal, and identity remain where used by the requested scaffold. No underlying protected-core files, private identity data, physical-core descriptions, seal values, or private memory stores are included. Whether these generic interface names/algorithms belong in the public patch is for Strider to decide; their architecture was not guessed or rewritten.
- Imported modules outside the requested scaffold are unresolved dependencies, not bundled implementations. This is not a drop-in runnable standalone assistant.
- Local loopback ports and generic credential-loading code remain. They contain no supplied credential values. Replace deployment placeholders and configure new paths before running.
- Exported reports are redacted. Judge/candidate/claim/context and retrieved memory excerpts were removed rather than publishing private memory. Do not treat the export as a byte-identical original trace. Public report hashes describe the exported files only.
- Simulator NPC errands are fictional. Timing, scores, model names, and game-generated action data are retained as technical test evidence, not real calendar or personal history.
- The situation gym's demonstrated run scored 38/100 and did not win. Its corrected retrospective was stored by the live pipeline, but lesson quality remains imperfect. The initial failed prototype is retained as test evidence; do not claim general intelligence gains.
- Word-game probes and the read-only training-recall fix demonstrate limited routing/recall behavior. No weights were trained. Exact source reports are dependencies of training_receipts.py and paths need configuring.
- The retired standalone word-game prototype is included for completeness and clearly named retired. The live version uses the production chat path.
- Deployment patch scripts are historical, order-sensitive integration notes. Do not execute them blindly against the public repository. The scenario integration touches relay hooks outside the six requested files; deploy.py documents those hooks, while the private relay itself is excluded.
- Game installers and scripts can mutate their configured local folders. Review them before executing. No binaries, virtual environments, third-party packages, profile/calendar files, protected-core snapshots, or credential files are included.
- License and third-party dependency compatibility require final verification; no new license is asserted.

## Validation

All included Python source is parsed without execution. Known identifier/credential/path patterns are scanned again. Public-target runtime tests were not run because the public repository's adapters/configuration are not supplied. Live-local behavioral results are included only as historical evidence.
